*Minecraft is an open-world sandbox game where plugins enable endless customization and server gameplay mechanics.*

I created a Minecraft plugin for custom crafting recipes, allowing server administrators and players to define unique recipes easily.

It's still in development and I plan to add color settings, change search engine, another widgets like music control, disk usage.

For design I was inspired by [wallpaper created by Probler](https://steamcommunity.com/sharedfiles/filedetails/?id=3025013651).
